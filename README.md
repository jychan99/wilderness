# 만촌2동 성당 ERP시스템 광야(wilderness)입니다.

이 프로그램은 만촌2동 성당 교리교사분들이 업무를 보다쉽게 처리하기 위해 개발되었습니다.

- 주간 업데이트 : 매주 토요일
- 월간 업데이트 : 매달 마지막 일요일
- 긴급 업데이트 : 버그 발생시

### 버전관리

**v** x.y.z
x : 대규모업데이트, UI, 기능 개편 및 확장개발시 업데이트
y : 소규모업데이트, 내부규칙 변동에 의한 유지보수 및 코드 리팩토링시 업데이트
z : 주간, 정기업데이트 및 버그수정시 업데이트

## 코드정보

POSITION ; 직책코드
0 : 관리자
1 : 회장
2 : 부회장
3 : 총무
4 : 서기
5 : 일반

GRADE_CODE ; 학년코드

K : 유치부
E : 초등부
E1 : 초1
E2 : 초2
E3 : 초3
E4 : 초4
E5 : 초5
E6 : 초6
M : 중등부
M1 : 중1
M2 : 중2
M3 : 중3
H : 고등부
H1 : 고1
H2 : 고2
H3 : 고3

BOARD_CODE ; 게시판코드
-> 아직 자유게시판밖에없어서 신경쓸필요는없지만 추후 확장개발시 고려할것
F : 자유게시판

GROUP_CODE ; 부서(동아리)코드
-> 레지오나 다른 그룹이 생겨 추후 확장개발시 고려할것.
N : (없음) None group
A : (복사단) Altar Server group
B : (밴드부) Band group
L : (전례부) Liturgia group
